# coin-change-math-agent
An AI agent for mathematical conjecture discovery and counterexample search in coin change systems.
第一阶段用代码实现了有以下功能的算法：
贪心算法（Greedy Algorithm）
动态规划最优解（Dynamic Programming）
自动生成三种面额的硬币组合
自动搜索贪心算法失效的反例
保存实验数据并绘制统计图表

后续将引入大语言模型，开发具有以下能力的数学研究智能体：
自动提出数学猜想
自主选择实验参数
调用 Python 数学工具验证猜想
根据反例修正猜想
